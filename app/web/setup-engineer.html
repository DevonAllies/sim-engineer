Setup Engineer

Reads iRacing telemetry (.ibt), pulls the setup stored inside it, and suggests what to change.

Recent sessions

Resize: turn on move mode, then drag an overlay's edge or corner to any width and height. Text size and font are set per overlay above.

Run iRacing in Borderless (or Windowed) mode so overlays can sit on top of it; true fullscreen hides them. Overlays only show while you are on track, or in move mode.
